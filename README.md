# PC Booster Store

Tienda online de componentes de PC hecha con **ASP.NET Core (Razor Pages)**, **Entity Framework Core** y **SQLite**.

Es la reescritura del trabajo práctico integrador de Programación III (UTN), que estaba en ASP.NET WebForms:
[Sebas-Re/TPFINAL_Prog3](https://github.com/Sebas-Re/TPFINAL_Prog3). De ahí vienen el schema, los datos de
prueba y el diseño con Bootstrap.
